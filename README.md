# Rainbow Spiral Art

Live demo: https://erionnezha.github.io/Rainbow-Spiral-Art/

A rainbow spiral drawn step by step on a black canvas — a faithful web port of a classic Python turtle script. The turtle walks forward a little further on every step while turning 91°, cycling through the full RGB rainbow.

## Original Python

`rainbow_spiral.py` runs with the Python standard library only (`turtle` ships with Python):

```
python rainbow_spiral.py
```

## Web version

Just open `index.html` in any browser — a single file, no dependencies, no build step. The drawing is recomputed and animated live on a full-viewport canvas.
